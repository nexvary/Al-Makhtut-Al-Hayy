# Product Roadmap

## Phase 0 — Foundation
- repository architecture
- manuscript/page data model
- provenance and revision model
- RTL design system
- CI baseline

## Phase 1 — First Living Manuscript MVP
Target: one manuscript, one complete interactive reading flow.

Deliverables:
- import manuscript pages
- page viewer with zoom
- line/region overlays
- HTR pipeline adapter
- verified transcription editor
- original vs modern Arabic synchronized view
- audio playback
- source-cited search

## Phase 2 — Ask the Manuscript
- corpus-grounded Q&A
- answer citations to page and line
- terminology glossary
- reader modes: general / student / researcher
- hallucination guardrails

## Phase 3 — Visual Knowledge
- interactive drawings
- instrument/object annotations
- historical timelines
- maps
- optional 3D object viewer
- short educational animations

## Phase 4 — Research Tools
- witness comparison
- variant readings
- editorial review workflow
- correction history
- export TEI/XML/JSON where appropriate

## Phase 5 — Mobile
- Android reader
- offline manuscript packs
- synchronized progress and bookmarks
- Arabic TTS support

## Candidate first corpus
A carefully licensed/public-domain manuscript associated with al-Zahrawi is a strong candidate because text + historical instrument illustrations demonstrate the platform's core value.

## MVP success criteria
A non-specialist should be able to open one difficult handwritten page and:
1. understand where each recognized line came from,
2. read a verified modern rendering,
3. hear it,
4. inspect difficult vocabulary,
5. ask a question and jump back to the cited source.
