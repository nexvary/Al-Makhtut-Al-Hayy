# Reader Modes

## قارئ عام
Shows verified/normalized/simplified text. Raw HTR is hidden unless no better layer exists.

## طالب
Adds explanatory material while keeping source-derived text visibly separate.

## باحث
Shows all layers including raw HTR, confidence, revisions and technical provenance.

## Accessibility
- RTL by default.
- Keyboard page navigation.
- Enter/Space activates a region card.
- Escape clears selection.
- Visible focus states.
- TTS is optional and uses the best available Arabic text layer.

## Offline
The first offline pack contains metadata/transcriptions only. Institution images are excluded by default so rights are not silently bypassed.
